# Weak Session IDs

## 개요

- 세션 ID(Session ID)는 로그인한 사용자를 서버가 식별하기 위해 발급하는 고유한 값입니다.
- Weak Session IDs는 세션 ID 생성 방식이 예측 가능하거나  
  엔트로피가 부족해 공격자가 유효한 세션 ID를 추측할 수 있는 취약점입니다.
- OWASP Top 10 2021 기준 **A07: Identification and Authentication Failures**에 해당합니다.

---

## Weak Session IDs 취약점 유형

| 구분 | 설명 | 특징 |
|------|------|------|
| 순차적 증가 | 세션 ID가 1, 2, 3... 순으로 발급 | 패턴 분석만으로 타 사용자 세션 예측 가능 |
| 시간 기반 | 현재 시간(timestamp)을 세션 ID로 사용 | 접속 시간을 알면 세션 추측 가능 |
| 짧은 길이 | 세션 ID 엔트로피 부족 (64비트 미만) | 브루트포스 공격으로 유효한 세션 ID 탐색 가능 |
| 약한 난수 | 암호학적으로 안전하지 않은 난수 알고리즘 사용 | 알고리즘 분석으로 다음 값 예측 가능 |

---

## 핵심 개념

- Weak Session IDs의 핵심은 **예측 가능성(Predictability)**입니다.
- 공격자가 세션 ID 생성 패턴을 파악하면 실제 인증 없이 타 사용자의 세션을 탈취할 수 있습니다.
- OWASP은 세션 ID가 최소 **64비트 이상의 엔트로피**를 가져야 브루트포스 공격을 방어할 수 있다고 명시합니다.
- 세션 ID가 탈취되면 공격자는 해당 사용자의 권한으로 모든 행위를 수행할 수 있습니다.

---

## 공격 방식 설명 (Session Prediction)

- 공격자는 Generate 버튼을 반복 클릭하며 세션 ID의 발급 패턴을 분석합니다.
- 세션 ID가 순차적으로 증가하는 것을 확인한 후, 현재 세션 ID 앞뒤 값을 쿠키에 직접 입력합니다.
- 서버가 세션 ID만으로 사용자를 인증하는 경우, 공격자는 해당 세션 ID의 사용자로 인식되어 계정을 탈취합니다.

---

## 예시

- 정상 세션 발급  
  → 서버가 `dvwaSession=9f3a2c8b1e47d605...` 형태의 암호학적 난수 발급  

- 취약한 세션 발급 (DVWA Low 레벨)  
  → `dvwaSession=1` → `dvwaSession=2` → `dvwaSession=3` 순으로 증가

- 공격 시도  
  → 공격자 세션 ID가 `5`임을 확인  
  → 쿠키 값을 `dvwaSession=3`으로 변조  
  → 서버는 세션 3번 사용자로 인식하여 해당 계정 접근 허용  

---

## 특징

- 세션 ID만 탈취하면 비밀번호 없이 계정 접근이 가능합니다.
- Burp Suite나 브라우저 개발자 도구로 쿠키 값을 간단히 변조할 수 있습니다.
- 피해자가 공격 사실을 인지하기 어렵습니다.
- Session Prediction, Session Hijacking, Session Sidejacking 등 2차 공격으로 이어집니다.

---

## 대응 방안

- 세션 ID는 **암호학적으로 안전한 난수 생성기(CSPRNG)**를 사용하여 생성합니다.
- 세션 ID는 **최소 128비트** 길이를 권장하며, 64비트 미만은 브루트포스에 취약합니다.
- 로그인, 권한 변경 시 새로운 세션 ID를 재발급(Session Regeneration)합니다.
- 쿠키에 `HttpOnly`, `Secure`, `SameSite` 옵션을 설정합니다.
- 일정 시간 미사용 시 세션을 자동 만료(Session Timeout)시킵니다.

---

## 정리

- Weak Session IDs는 예측 가능한 세션 ID 생성으로 인해 공격자가 타 사용자의 세션을 탈취하는 취약점입니다.
- 핵심은 **예측 가능성(Predictability)**이며, 충분한 엔트로피와 CSPRNG 적용으로 방어합니다.
- OWASP DVWA Low 레벨은 세션 ID를 1씩 증가시키는 가장 단순한 형태의 취약점을 구현하고 있습니다.
